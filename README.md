# Telewebion Local Relay — پخش بی‌فریز تلوبیون از خارج ایران

یک برنامه‌ی کوچک پایتونی که روی **دستگاه خودتان** (کامپیوتر، رزبری‌پای، باکس قدیمی اندروید با Termux) اجرا می‌شود و پخش زنده و **کچ‌آپ (دیدن برنامه‌ی گذشته)** تلوبیون را از خارج ایران روان می‌کند.
بدون سرور، بدون حساب، بدون هزینه. فقط پایتون ۳٫۸ به بالا (هیچ کتابخانه‌ی اضافه‌ای لازم نیست).

A tiny Python relay you run on your own always-on device. It makes Telewebion live TV and catch-up play smoothly from outside Iran.
No server, no account, no dependencies (Python 3.8+).

## چرا فریز می‌شد؟ / Why it froze
لیست پخش هر کانال تلوبیون ۱۸۰۰ قطعه (حدود ۳۲۵ کیلوبایت) است و پخش‌کننده هر ۲ ثانیه آن را دوباره می‌گیرد، و هر قطعه یک اتصال تازه به ایران می‌خواهد.
در ساعات شلوغ ایران (عصر و شب) این‌ها پهنای باند را می‌خورند و پخش می‌ایستد. این رله:
- لیست پخش را به ۸ قطعه (حدود ۲ کیلوبایت) کوتاه می‌کند،
- اتصال‌های گرم و پایدار به تلوبیون نگه می‌دارد،
- قطعه‌های جدید را چند‌تا‌چند از قبل می‌گیرد و آماده می‌دهد.

## نصب و اجرا / Run
```
python tw_local_relay.py
```
آدرسی که چاپ می‌کند (مثلاً `http://192.168.1.20:8765/playlist.m3u`) را **یک بار** در TiviMate، VLC، Kodi و ... به‌عنوان پلی‌لیست بگذارید. همین.
Put the printed address into TiviMate / VLC / Kodi as a playlist URL. That's all.

- لیست را خودش از پلی‌لیست عمومی می‌سازد و لینک‌های تلوبیون را به خودش وصل می‌کند.
- **کچ‌آپ در TiviMate:** کانال‌ها علامت `catchup="shift"` می‌گیرند.
- **VOD کچ‌آپ:** گروه‌های «تلوبیون Catch-up VOD: شبکه یک» و ... با برنامه‌های اخیر هر شبکه‌ی اصلی.
- کیفیت را خود پخش‌کننده خودکار انتخاب می‌کند.

### تنظیمات (اختیاری، متغیر محیطی)
| متغیر | پیش‌فرض | معنی |
|---|---|---|
| `TW_PORT` | `8765` | پورت |
| `TW_PLAYLIST` | پلی‌لیست عمومی `persian-tv` | پلی‌لیستی که باید تبدیل شود |
| `TW_BIND` | `0.0.0.0` | با `127.0.0.1` فقط روی همین دستگاه |
| `TW_AUTOUPDATE` | `1` | `0` = به‌روزرسانی خودکار خاموش |

## اجرای خودکار با روشن شدن دستگاه / Start on boot
**ویندوز:** Task Scheduler ← Create Task ← Trigger: «At startup» ← Action: `pythonw.exe` با آرگومان مسیر `tw_local_relay.py`.
**لینوکس / رزبری‌پای** (فایل `/etc/systemd/system/twrelay.service`):
```
[Unit]
Description=Telewebion local relay
After=network-online.target
[Service]
WorkingDirectory=/home/pi/telewebion-local-relay
ExecStart=/usr/bin/python3 tw_local_relay.py
Restart=always
[Install]
WantedBy=multi-user.target
```
سپس `sudo systemctl enable --now twrelay`.
**اندروید (Termux):** `pkg install python` و `python tw_local_relay.py` (برای اجرای خودکار از Termux:Boot استفاده کنید).

## به‌روزرسانی خودکار / Auto-update
هنگام شروع و هر ۶ ساعت، برنامه `version.json` را از همین مخزن می‌خواند. اگر نسخه‌ی تازه‌تری بود، فایل‌ها را می‌گیرد، **هش SHA-256 هر فایل را تطبیق می‌دهد**، کامپایل‌شدنشان را بررسی می‌کند، نسخه‌ی قبلی را با پسوند `.bak` نگه می‌دارد و دوباره اجرا می‌شود. هر خطا = ماندن روی نسخه‌ی فعلی.
خاموش کردن: `TW_AUTOUPDATE=0`.

⚠️ **نکته‌ی امنیتی:** به‌روزرسانی خودکار یعنی کدی که صاحب این مخزن در GitHub می‌گذارد روی دستگاه شما اجرا می‌شود. اگر به این اعتماد ندارید، `TW_AUTOUPDATE=0` بگذارید و خودتان به‌روز کنید.

## محدودیت‌ها / Limits
- دستگاه باید **روشن بماند**.
- سرعت واقعی هنوز به اینترنت شما بستگی دارد؛ این برنامه فریز ناشی از «اتصال و لیست سنگین» را کم می‌کند، نه کندی خود خط.
- **شبکه‌ی ۳ و ورزش** از هر IP خارج ایران خطای ۴۵۱ می‌دهند (محدودیت حق پخش تلوبیون). این برنامه نمی‌تواند آن را حل کند.
- پخش زنده 2 تا 6 ثانیه از لحظه‌ی واقعی عقب‌تر است.
- این یک ابزار مستقل است و ربطی به شرکت تلوبیون یا صداوسیما ندارد؛ فقط از API و CDN عمومی خودشان می‌خواند. مسئولیت استفاده با خود شماست.
